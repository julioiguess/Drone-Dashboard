# refactor

## Instructions

Use this skill whenever redundant lines of code appear throughout a program and reduce this by putting logic into functions to improve modularity. Additionally, check for logial errors in the code and resolve them as such. Moreover, if there are any features that have not yet been implemented (e.g. buttons that do not have actions set for them), then they can be implemented as well.
Lastly, check for edge cases to ensure that no violations are made (e.g. if an item belongs to an item container, then its position cannot be outside of the item container's area based on the coordinates provided and the area of the item container).
